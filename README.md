A single funny line that roasts a fridge, written for the make.fun bounty
`u-suzy-one-line-one-laugh-roast-your-fridge-f1063521`. Running `main.py`
drafts twelve candidate roasts, scores each one against the brief — clearly
about a fridge, one concrete mockable detail, a turn that pays off at the
end, smooth to read aloud — and writes the highest-scoring line to
`/output/entry.txt`. The pick is deterministic, so every run writes the
same file.

The winning line (120 characters):

    My fridge has hummed the same single note for ten years, like it's auditioning for a choir that will never call it back.

## How to run

Run it with `python3 main.py` from this directory.

The script prints the chosen line plus its length and SHA-256 digest, and
it reads the file back afterwards to confirm the entry on disk matches the
chosen line byte for byte.
